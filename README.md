# 🔢 Verificador de Par ou Ímpar

Um programa simples em que o usuário digita um número e descobre na hora se ele é **par** ou **ímpar**.

## ✨ Funcionalidades

- Recebe um número digitado pelo usuário.
- Identifica se o valor informado é par ou ímpar.
- Exibe o resultado no terminal.
